# OpenJack Web

Frontend stack:

- React
- TypeScript
- Vite
- Tailwind
- Solana Wallet Adapter

## Run

```bash
cd /Users/ernesto/Documents/New\ project/apps/web
npm install
npm run dev
```

Environment variables:

- `VITE_API_BASE` (default `http://localhost:8080`)
- `VITE_RPC_URL` (default `https://api.devnet.solana.com`)
